## `> whoami`

Développeur web spécialisé **Laravel / Symfony / Prestashop**, je travaille sur des **applications métiers à forte valeur ajoutée** : PIM, ERP, plateformes e-commerce, outils internes.

Mon approche est **pragmatique** : une architecture claire, des flux de données fiables, des fonctionnalités qui servent réellement les équipes terrain.

En parallèle, je construis une double compétence en **Big Data & IA** --- avec un objectif concret :
> **Utiliser la donnée pour automatiser, fiabiliser et accélérer la prise de décision.**
